# Безпека

## Повідомити про вразливість
Напишіть власнику репозиторію приватно (GitHub → Security → «Report a vulnerability»), без публічного issue.

## Що варто знати
- Програма **не збирає і не зберігає паролі**. Вхід у Google виконується у справжньому браузері (Chrome/Edge/Chromium)
  в окремому профілі програми; пароль вводиться лише на сторінці Google.
- Профілі браузера лежать у папці даних програми на комп'ютері користувача (кожен обліковий запис — окремий профіль).
  Хто має доступ до цієї папки, має доступ до сесії Google, тож не копіюйте її й не передавайте.
- Оновлення розкладу завантажуються лише з цього репозиторію, а їхня контрольна сума (SHA-256) звіряється з `manifest.json`.
- Посилання на завантаження нової версії програми відкриваються, лише якщо вони ведуть на GitHub цього репозиторію по https.
- **Стара Python-версія** сама підміняє свій код і `dashboard.html` з гілки `main` (з перевіркою суми з `manifest.json`).
  Тому доступ на запис у `main` фактично дає виконання коду на всіх встановлених копіях. Для власника репозиторію:
  увімкніть двофакторну автентифікацію GitHub і захист гілки `main` (заборона force push і видалення).
- Інсталятори в релізах: Windows-збірка поки не підписана (SmartScreen покаже попередження); macOS-збірка підписується й
  нотаризується, якщо в репозиторії задано секрети Apple (див. `beta/README.md`).
