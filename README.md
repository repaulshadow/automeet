# Auto Meet

Програма сама заходить на пари в Google Meet за розкладом: знаходить посилання в Google Classroom, вимикає мікрофон і камеру,
заходить на початку пари й виходить наприкінці. Для студентів (за групою) і викладачів (за прізвищем, з кнопкою «Заміняю пару»).

## Завантажити
Актуальна версія — на сторінці [Releases](https://github.com/repaulshadow/automeet/releases) (файли мають постійні назви):

| Система | Файл |
|---|---|
| Windows | `AutoMeet-Windows.exe` |
| macOS (Apple Silicon: M1, M2, M3…) | `AutoMeet-macOS-arm64.dmg` |
| macOS (Intel) | `AutoMeet-macOS-intel.dmg` |

Потрібен встановлений Google Chrome або Microsoft Edge (якщо їх немає, програма сама завантажить Chromium).
Програма сама перевіряє нові версії та пропонує завантажити оновлення.
Якщо Windows чи macOS попереджають про невідомого видавця — див. [`beta/README.md`](beta/README.md).

## Як користуватися
1. Запустіть програму і виберіть роль: студент (оберіть курс і групу) чи викладач (оберіть себе зі списку).
2. Увійдіть у свій Google-акаунт у вікні браузера, яке відкриється (один раз).
3. Програма зв'яже курси Classroom з предметами розкладу й далі працює сама: можна згорнути до трею.
4. Угорі праворуч — перемикач **облікових записів** (до 5): у кожного свій вхід у Google, галочка «Працює» вмикає кілька одночасно.
5. **Налаштування:** курси Classroom, група/викладач, видалення запису, оновлення розкладу й програми, автозапуск.

## Структура репозиторію
| Що | Де |
|---|---|
| Програма (Electron, без консолі) | [`beta/`](beta/) — докладно в [`beta/README.md`](beta/README.md) |
| Розклад дзвінків і груп | `schedule.json` (оновлюється з гілки `main`, звірка SHA-256 через `manifest.json`) |
| Стара Python-версія | `auto_meet.py`, `dashboard.html` — лишається для встановлених копій, які оновлюються з `main` |
| Збірка й релізи | `.github/workflows/build-beta.yml` (тег `v*` → релізи з інсталяторами) |

## Для іншого навчального закладу
Змініть `REPO` у `beta/src/config.js` та підготуйте свій `schedule.json`. Збірка й оновлення працюватимуть зі своїм репозиторієм.
